# Pi 学习网站需求

## 教学对象与受众

以 `earendil-works/pi` 的固定源码版本为教学依据，面向了解基本 JavaScript、尚未建立 Agent 心智模型的初学者。路径为「直觉 → 运行过程 → 代码 → 自测」，所有实验为浏览器教学模拟。

## 需求与功能分解

| 需求 | 功能点 | 验收方式 |
| --- | --- | --- |
| R1 建立整体认识 | 项目职责、三层架构、渐进式课程、先修知识 | 每课有明确目标与中文解释，模块可以选择查看 |
| R2 看懂运行过程 | loop 步进/播放/暂停/重置、工具成功/失败/steering、事件日志 | 各场景运行到结束，重置后状态一致 |
| R3 理解核心实现 | 消息角色与上下文、工具 Schema/执行结果、事件、会话树、扩展 | 选择元素能看到与源码一致的解释，演示和真实执行清晰区分 |
| R4 阅读真实源码 | 固定 commit、文件与符号、代码分段解释、官方 permalink | 链接指向同一版本；教学简化代码显式标记 |
| R5 持续学习 | 全文搜索、章节前后切换、课程进度、本地笔记、选择题与解析 | 刷新保留状态；损坏/不可用存储不使页面崩溃 |
| R6 美观且可访问 | 轻量学习工作台、响应式导航、键盘操作、低动态偏好 | 390/768/1440 宽度无横向溢出，键盘可用，浏览器无运行错误 |

## 技术调研结论

- React 组件与静态 TypeScript 数据：课程数量有限，无需 CMS 和服务端。
- Vite：开发/生产静态构建；ESLint flat config 与 TypeScript strict 检查。
- 原生 CSS 与 SVG：轻量可控、可访问，使用有限过渡和状态驱动动画，无额外动画框架。
- URL hash：支持静态托管和课程直达；浏览器后退恢复课程。
- localStorage：保存进度和笔记，所有读写捕获异常并校验形状。
- Playwright：验证真实用户操作、刷新持久化、布局、键盘与错误分支。

## 视觉方案

采用「打开一本可操作的工程手册」的学习工作台。左侧课程目录、中间讲解和实验、右侧本课目录；移动端收起目录。底色 #f7f8fa、纸面 #ffffff、正文 #242735、紫色 #7160d8、浅紫 #eeebfb、绿色 #49866b。界面使用 Segoe UI / 微软雅黑系统字体；标志 π 使用 Georgia，代码使用 Consolas。

主视觉是可步进的 Agent loop，连接线表达信息流，色彩仅表达当前步骤、工具结果与学习状态。避免堆砌概览统计、装饰图片或无关仪表盘。默认呈现可阅读课程，而不是额外的营销落地页。

## 完成标准

上述功能在纯静态环境可使用，课程内容有固定源码依据，生产构建、ESLint、核心 Playwright 测试通过，保留验证记录和本地启动说明。
