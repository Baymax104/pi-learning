## Context

Inside Pi 是面向初学者的中文课程工作台。沿用浅灰底、白色纸面、紫色交互强调和现有课程内容。

## Decisions

1. 缩短课头和学习目标所占的纵向空间。实验播控紧接流程图，并用高亮和当前数据说明进度。
2. 使用原生 dialog 管理移动目录的焦点和 Escape。课程选中后滚到内容起点。
3. 为每个标签保留稳定面板，按需挂载内容。离开实验标签时暂停播放。
4. 源码步骤在桌面和代码并排，手机上放在代码上方。滚动限制在代码窗内。

## Risks / Trade-offs

- 小屏步骤控件可能换行。用 320px、390px 和 768px 视口检查控制栏、目录和代码。
- 标签持久挂载会影响选择器。Playwright 测试在当前可见面板内定位控件。
